# Packaging schemas

Unmodified Agent Plugins 1.0.0 JSON schemas, retrieved on 2026-10-01 from:

- https://agent-plugins.org/schemas/1.0.0/plugin.schema.json
- https://agent-plugins.org/schemas/1.0.0/mcp.schema.json

Packaging validates against these versioned schemas locally, so an unavailable schema website does not block the ZIP build. A different manifest schema version still uses its declared URL.
