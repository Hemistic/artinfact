# 点状图谱与卡片白板

来源：用户指定的 `codex://threads/01a104d2-db8e-7290-a6e9-6e2c5ccc4c7d`，本项目 `.context/show-depth-demo.mjs` 和 `.context/depth-demo/` 保存的原实现。

0.12.3 将参考预览构建时的图谱变换展开为 `src/whiteboard/network.ts`，直接用于生产构建。保留原快引力模拟、稳定标签布局、轻连线、浮动节点目录和详情、共用画布工具栏与样式。运行时不再依赖演示脚本、硬编码论文或演示图谱 JSON。

主页三入口使用 `workspace-graph-views.ts` 的明确模式：知识图谱默认 `constellation`，卡片白板默认 `editor`，数据处理打开白板信源和任务资料面板。图谱 JSON 与有限证据摘录通过工作区 Wiki 服务读取并安全嵌入；PDF 仍是同源 Markdown 的回跳目标。白板继续使用原 MCP、卡片库和独立持久文件，不重写图谱为白板、不覆盖已有卡片或 Pages 缓存。

图谱节点选中使用已验证来源的 iframe 消息提供聊天上下文，来源 PDF 必须属于当前工作区。白板退出和刷新等待初始化及写队列；图谱、白板模式切换不跨工作区发送任务。原网络模拟和标签回归以及生产工作区隔离、转义和数据保留测试纳入插件测试。
