# 图表卡片展示（0.12.16）

0.12.16 将画布中的图表卡片精简为只有完整图片和下方图题／表题。移除卡片标题、类别、摘要、笔记折叠栏和操作栏；边框、阴影和卡片背景均取消，四周仅留 4 px。图像高度随自身比例和宽度自然变化，去掉 0.12.15 的固定图片框及最小卡片高度。原始笔记数据和分析功能保留。

缩放保持图片比例，横向或纵向拖动均换算成图片宽度；宽度支持 220–1400 px。卡片尺寸菜单只保留宽度控制。缩放手柄平时隐藏，悬停或键盘聚焦时出现。真实 DOM 高度低于数据模型的 152 px 下限时，测量写回按模型下限处理，避免循环保存。

浏览器预览核对：边框 0 px、阴影 none、边距 4 px，无标题、操作栏或摘要；Fig. 1 的卡片高 444 px，其中图片 389 px、图题 42 px，仅剩约 14 px 的边距与间隔。截图 `.preview-data/image-caption-only-01216.jpg`。

以下是 0.12.15 的历史说明，固定高度图片框、摘要和卡片操作栏已由上述 0.12.16 实现替换。

图和表采用独立的图片卡片：图像在前，完整图题／表题在后；内容摘要、表格原始文本和用户笔记折叠显示。公式卡片继续使用 KaTeX。此项修改只改变展示，保留既有卡片正文、共享引用、来源和连线。

图像使用 `object-fit: contain`，取消普通笔记预览的 154 px 内容限制和 128 px 图片限制。每张图片保留原始比例，不通过剪裁填满卡片。点击图片可打开完整图片查看器。

拖动右下角手柄可改变卡片宽度及图片显示高度。也可点击“调整大小”，使用检查面板中的尺寸滑块或“大图”。宽度范围 320–1400 px，图片高度范围 120–1600 px。实际拖动距离按画布缩放比例换算；尺寸写入既有 MCP 白板持久化，邻近卡片通过现有排布逻辑避让。

标题来自同源 MinerU 的 `image_caption` / `table_caption`，单独返回完整字段，不依赖已截断的卡片名称或 420 字预览。缺少图题／表题时明确显示尚未提取，不以内部标识或表格 HTML 代替。

验证使用 Seg2Grasp 的隔离工作区副本：10 张图、2 张表的图片均成功加载，无内容高度裁切，图像完整按比例显示；滑块和拖动缩放均有效，重新加载后尺寸保留，摘要可展开／收起。预览页没有浏览器错误。截图保存在本地 `.preview-data/complete-{figure,table}-01215.jpg`。此次浏览器测试不等同于 Codex 原生 Sidebar App 实测。
