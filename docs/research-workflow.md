# Artinfact 节点研究白板

知识图谱保持多论文之间的真实关系。白板用于组装“信源 → 分析模板 → 输出”，不自动把白板连接写成知识图谱事实。

## 使用

底栏“白板”只管理白板：新建、切换、删除及恢复。资料目录、跨白板复用卡片和 Agent 任务都在左侧加号中。删除当前白板会切换到剩余白板；删除最后一张时保留空状态，刷新不会重新导入已删除白板。

选中卡片后按 Delete 或 Backspace 移出白板，关联连线一并移除；Shift 点击可多选并批量删除，撤销恢复同一批卡片及连线。点击线条本身可选中连接，通过详情栏“删除连接”或键盘删除；中间标签单击仍是原位文字编辑，编辑器内的删除键仅修改文本，Esc 取消编辑。白板删除使用可恢复归档，不删除 PDF、共享卡片或图片附件；`whiteboard_archive` 接收 `archived:true/false`，与其他 MCP 写入一样校验 revision 和 requestId。

1. 从当前 workspace 的主页进入卡片白板，点击底部“＋”。
2. 选择 PDF 全文、图片、表格、公式、批注、AI 洞察或已同步 Pages。每个条目独立成卡，图表等仍指向原 PDF 的 documentId、annotationId 与页码。未转换的 PDF 要先在阅读器完成本机 MinerU 解析。
3. 添加“相同相似”“图表比较”或“公式讲解与推导”节点，从输入卡片向模板连线。相同相似至少需要两份不同资料。
4. 连线上始终显示文字；单击文字在原位置输入要求，Enter 或失焦保存，Escape 取消。也可点击连线，在检查面板修改。
5. 编辑节点提示词后点击该节点“运行”；运行会先通过 MCP 保存当前提示词，也可单独点“保存要求”。仅运行将所选上游资料和连接要求发给当前 Codex Agent；连接不会触发执行。任务状态及结果通过 MCP 返回。浏览器预览只能记录发送，不能证明宿主 Agent 执行成功。
分析中的相同点、差异、创新关系和推导步骤可通过 `findings` 回传为独立条目卡片，每条都有依据。用户可只挑选其中几张接到输出，结果卡来自旧版分析时会阻止误用。

6. 模板完成后连接 Pages 输出或生图输出，再单独点击输出节点“运行”。Pages 新建私有页面，保留之前用户编辑的页面；生图使用实际生成工具并保存图片附件。
7. 已关联 Pages 卡片显示标题和短 Markdown 摘要，点击原生 `codex://space/<pageId>` 打开。编辑后用“同步／关联设置”同步正文缓存，再用于后续分析；没有实时跨插件订阅。

## 数据与 MCP

白板、卡片、连线、节点要求、任务和结果保存于当前 workspace 的 `knowledge-map/whiteboards.json`。图片在同目录 `assets/`，Pages 同步缓存位于 workspace `.pages/`。原 PDF、批注及 MinerU Markdown/JSON 继续使用原文档目录，不复制一套独立 PDF/Markdown 信源。

- `whiteboard_sources` / `whiteboard_source_read` / `whiteboard_source_sections`：目录及分段正文。图表正文来自同源结构 JSON，全文来自同源 Markdown，Pages 正文来自已授权完整缓存。
- `whiteboard_source_image`：读取真实 MinerU 图表图片；图片缺失时明确报告，不能仅看图注就声称看过图片。
- `whiteboard_workflow_run`：冻结指定节点的上游范围、连线文字、模板要求与信源修订，返回 queued 任务。
- `whiteboard_workflow_read` / `whiteboard_task_status`：Agent 读取任务、领取及记录真实失败。
- `whiteboard_workflow_complete`：保存实际研究结果。引用须匹配原文精确 UTF-16 偏移；Pages 需实际 read_page 的完整块、标题和链接；生图需已保存的图片附件 ID。

结果和用户的要求分别保存，Agent 不覆盖用户笔记。输入或连线变更会拒绝旧任务的回传；上游结果过期时须先重新运行上游。公式以本机 KaTeX HTML + MathML 展示，推导模板要求区分论文步骤和补充推导，不补造定义、实验数值或新颖性结论。

本机自动测试使用隔离的测试资料和页面数据，不能替代真实 Pages 创建及生图的宿主端到端验证。

## 组合范围与证据约束

节点详情的“本次组合”显示直接输入及每条线的要求，模板框架可展开查看。`whiteboard_workflow_read.directInputs` 是实际组合的内容，`inputs` 包含沿运行输入线的背景资料；Agent 不应把背景展开为所有分析结果。连接分析模板表示使用整份结果，连接发现条目表示只使用选中的发现。

模板到发现卡片的自动连线是来源联系，不参与输出组合。旧版保存为输入线的同源关系也不扩大范围。跨白板复用发现仍保留来源校验，原文、原模板要求或输入连线变化后阻止过期发现进入新输出。

“相同相似”先对齐问题、机制、假设与实验口径，再区分同一、相似、差异、互补、冲突和创新关系。确认的相似发现与比较结果需有两份不同文档的精确引用，不能用同一 PDF 的两个片段冒充两篇依据；待验证设想单独标明。公式模板要求符号、单位、前提、逐步推导与原文对应位置，区分原作者推导和补充解释。


## 论文全景模板（0.12.14）

工作区首页 → 图谱 / 白板 → 卡片白板 → ＋ 添加资料 → 选择 PDF → 展开论文全景。只使用当前工作区已解析的 PDF；新建独立白板，不改原白板。当前论文的全文、真实章节与子章节、图表、公式、批注和已保存洞察均成为卡片。没有洞察结果就没有占位洞察卡片。默认从全文和前几个章节开始阅读；拖动画布浏览，添加资料的搜索可定位已有卡片，适应画布查看全貌。

结构优先来自同源 MinerU tree.json 与 blockIndex；缺少结构树时使用原 Markdown 标题。图表/公式与章节通过实际块索引关联，批注只有唯一页面归属时才绑定章节；有歧义的内容保留为未定位。正文中明确的 Figure/Fig/Table/Equation 编号引用形成跨章节引用线，不把位置关系当成因果关系。

虚线“资料联系”表示章节归属及正文引用；实线“运行输入”参与节点执行。连线的检查器可修改用途。资料联系不会把全部祖先加入分析输入；选一张公式卡片连到公式模板，只分析选中的公式，并读取所属 PDF 作为背景。连线不会自动运行。拖动或点击连线入口会拒绝重复、自连和循环输入；旧数据有循环仍由运行前校验拒绝。

公式使用本机 KaTeX HTML 和可访问 MathML，CSS 与全部 WOFF2 字体内嵌，不请求 CDN。源码、正文分页、引用校验与原 PDF 归属保留。单份论文全景最多 500 张卡片，超过时明确提示按章节拆分；不会静默丢弃。


## 简洁展示

公式和证据的简洁展示必须由 Agent 阅读原文后整理，不能用脚本生成解释。公式 presentation:{type:"formula",latex,explanation,symbols:[{latex,meaning}]}，证据 presentation:{type:"evidence",statement,explanation}；note 保留完整资料和分析，citations 保留准确依据。符号缺失定义写未知，不猜测。不要在展示字段中放 YAML、文件名、页码或同步状态。
连线标签固定在曲线中点，卡片拖动和画布缩放使用同一坐标。编辑时不打开检查面板；Enter 或失焦保存，Esc 取消。标签输入保持到提交完成，错误时保留草稿。公式和证据卡片仅显示展示内容，单击可看完整卡片和来源。
