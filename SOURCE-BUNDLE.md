# Artinfact 0.13.52 corresponding source

The repository contains the actual integration source in src/, build scripts, locked dependency metadata, focused regression check sources, imported vendor snapshots, required third-party runtime assets and notices. Node.js 22+ is required. Build with npm ci and npm run build. The complete Windows x64 release ZIP additionally includes dist/ and a local marketplace for installation; GitHub's automatic source ZIP does not include dist/.

Optional MinerU environments and model weights are installed separately. User workspaces, authentication credentials, support correspondence and private account bindings are excluded. See LICENSE, NOTICE.md and vendor/component notices. Normal builds use the included vendor snapshots and do not require an original developer checkout.
