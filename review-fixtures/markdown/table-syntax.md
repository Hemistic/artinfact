## 操作清单

1. 编辑文字，Tab 切换；最后一格按 Tab 新增一行。
2. 从边界加号插入行列；从小手柄菜单设置对齐、删除行列。
3. 每次结构操作后检查 Ctrl+Z 和 Ctrl+Shift+Z。
4. 拖动行列手柄调整顺序，核对表头与内容。
5. 300 / 420 / 720px 宽度、75% / 150% 缩放下检查菜单与滚动。
6. 保存重载、只读预览、返回编辑，结构和排版应一致。
